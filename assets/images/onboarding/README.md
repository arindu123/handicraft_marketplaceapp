# Onboarding photographs

These JPEG assets are bundled locally through the onboarding directory in `pubspec.yaml`:

- `discover.jpeg`: handmade baskets and ceramics collection
- `artisans.jpeg`: artisan shaping a clay pot
- `delivery.jpeg`: ceramic bowl being wrapped for delivery

The stories and accessible image descriptions are defined in
`lib/features/auth/widgets/onboarding_story.dart`.
Images are cropped to the rounded photo frames with `BoxFit.cover`.
